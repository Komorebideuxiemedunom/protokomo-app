Politique de confidentialité

Application ProtoKomo pour iPhone · en vigueur le 12 octobre 2026

En bref

ProtoKomo n'a pas de serveur et ne collecte aucune donnée. L'app parle directement, depuis votre iPhone, à Anthropic (pour Claude) et à GitHub (pour votre site), avec vos propres comptes. L'éditeur n'a accès ni à vos sites, ni à vos demandes, ni à vos identifiants.

Ce qui reste sur l'iPhone

  • Votre clé API Claude et votre jeton GitHub : dans le trousseau de l'iPhone, accessibles seulement quand il est déverrouillé, jamais copiés vers un autre appareil.
  • Vos conversations avec Claude et les aperçus : dans l'app, chiffrés par la protection des données d'iOS. « Se déconnecter et effacer les données » (Réglages) les supprime.
  • Vos réglages : modèle, plafond de dépense.

Ce qui part, et vers qui

  • Anthropic (api.anthropic.com), avec votre clé : vos demandes, le code de votre site (monté dans un espace de travail hébergé par Anthropic) et ce que Claude produit. Ces données sont traitées selon les conditions d'Anthropic applicables à votre compte. Le jeton GitHub transmis pour ouvrir votre dépôt reste chez Anthropic, hors de l'espace de travail de Claude.
  • GitHub (api.github.com), avec votre jeton : la liste de vos dépôts, l'historique et le brouillon de votre site, la publication. Voir la déclaration de confidentialité de GitHub.
  • Apple : l'achat de ProtoKomo Premium passe par l'App Store.

Ce que l'app ne fait pas

Pas de compte ProtoKomo, pas de publicité, pas de mesure d'audience, pas de pisteur, aucune donnée vendue ou partagée. La démonstration intégrée fonctionne entièrement sur l'iPhone.

Vos droits

Comme l'éditeur ne détient aucune donnée vous concernant, il n'a rien à consulter, corriger ou effacer. Pour les données traitées par Anthropic ou GitHub, adressez-vous à eux. Pour toute question : page d'assistance. Vous pouvez aussi saisir la CNIL.

Évolutions

Cette politique sera mise à jour avant toute évolution qui changerait l'usage des données, et la date ci-dessus changera.
