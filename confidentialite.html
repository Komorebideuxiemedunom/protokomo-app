Politique de confidentialité

Application ProtoKomo pour iPhone · en vigueur le 12 octobre 2026 (mise à jour : poste de travail)

En bref

ProtoKomo n'a pas de serveur et ne collecte aucune donnée. L'app parle directement, depuis votre iPhone, à GitHub, avec votre compte. Claude Code travaille dans votre propre dépôt GitHub (votre « poste de travail ») avec votre abonnement Claude. L'éditeur n'a accès ni à vos sites, ni à vos demandes, ni à vos identifiants, et ne voit jamais votre jeton Claude.

Ce qui reste sur l'iPhone

  • Votre jeton GitHub : dans le trousseau de l'iPhone, accessible seulement quand il est déverrouillé, jamais copié vers un autre appareil.
  • Vos conversations avec Claude et les aperçus : dans l'app, chiffrés par la protection des données d'iOS. « Se déconnecter et effacer les données » (Réglages) les supprime.

Ce qui part, et vers qui

  • GitHub (api.github.com), avec votre jeton : la liste de vos dépôts, l'historique et le brouillon de votre site, la publication, et votre poste de travail, un dépôt privé « protokomo-poste » créé dans votre compte. L'app y range votre jeton GitHub, chiffré pour GitHub, dans les secrets du dépôt, et y envoie vos demandes ; l'avancement et les aperçus y sont enregistrés. Voir la déclaration de confidentialité de GitHub.
  • Anthropic : dans votre poste de travail, Claude Code (le programme officiel d'Anthropic) envoie à Anthropic vos demandes et le code nécessaire, avec votre abonnement Claude, selon les conditions d'Anthropic applicables à votre compte. Vous connectez cet abonnement vous-même, sur la page d'Anthropic ; le jeton est rangé dans votre dépôt et ne passe jamais par l'app.
  • Apple : l'achat de ProtoKomo Premium passe par l'App Store.

Ce que l'app ne fait pas

Pas de compte ProtoKomo, pas de publicité, pas de mesure d'audience, pas de pisteur, aucune donnée vendue ou partagée. La démonstration intégrée fonctionne entièrement sur l'iPhone.

Vos droits

Comme l'éditeur ne détient aucune donnée vous concernant, il n'a rien à consulter, corriger ou effacer. Pour les données traitées par Anthropic ou GitHub, adressez-vous à eux. Pour toute question : page d'assistance. Vous pouvez aussi saisir la CNIL.

Évolutions

Cette politique sera mise à jour avant toute évolution qui changerait l'usage des données, et la date ci-dessus changera.
