ProtoKomo

Modifiez votre site web depuis l'iPhone en expliquant ce que vous voulez en français. Claude Code fait la modification avec votre abonnement Claude, vous voyez le résultat sur mobile, tablette ou en 16:9, puis vous publiez.

Une question, un problème ? Écrivez-nous

Questions fréquentes

De quoi ai-je besoin ?

D'un abonnement Claude (Pro ou Max) et d'un site dont le code est sur GitHub. Pas de clé API. L'app vous guide : jeton GitHub, installation de votre poste de travail (un dépôt privé où Claude Code tourne pour vous), puis connexion de votre abonnement Claude, une fois par an. La démonstration intégrée se passe de tout cela.

Combien ça coûte à l'usage ?

Rien de plus : chaque demande compte dans les limites de votre abonnement Claude, et le poste utilise les minutes GitHub Actions incluses dans votre compte GitHub (2 000 par mois sur un compte gratuit). Annuler, publier et voir l'aperçu ne consomment pas votre abonnement.

Le poste de travail ne démarre pas

Si GitHub indique un problème de facturation ou de limite de dépense, vos minutes gratuites de GitHub Actions sont épuisées ou un paiement a échoué : voyez « Billing and plans » dans les réglages de votre compte GitHub.

Que débloque ProtoKomo Premium ?

Les demandes à Claude depuis l'iPhone. Un seul achat, à vie, sans abonnement. Parcourir vos sites, l'aperçu et la démonstration sont gratuits. Pour retrouver votre achat sur un nouvel iPhone : Réglages → « Restaurer un achat ».

Mes modifications sont-elles en ligne tout de suite ?

Non. Chaque demande est enregistrée dans un brouillon (la branche « protokomo-brouillon » de votre dépôt). Rien ne change sur votre site avant « Publier ». Une modification se défait avec « Annuler la dernière modification ».

Le site ne s'affiche pas dans l'aperçu

Les sites qui se construisent (Vite, Astro, Next…) sont préparés par Claude : touchez « Demander l'aperçu à Claude ». Un site qui a besoin d'un serveur (base de données, PHP) ne peut pas s'afficher en entier.

Le jeton GitHub est refusé

Créez un jeton « fine-grained » avec l'accès à vos sites et la permission « Contents » en lecture et écriture, puis collez-le dans Réglages → GitHub.
